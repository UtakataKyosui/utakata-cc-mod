# prompt-retrospective

Claude Code の会話ログ (`~/.claude/projects/**/*.jsonl`) から自分が送ったプロンプトを集計し、改善点のレポートを書き出す。外部アプリのデータは使わない。

## 使い方

```text
/retrospective
/retrospective 30
/retrospective help
```

日数を省略すると設定の `days`（既定7日）を使う。レポートは `reportDir`（既定 `reports`、セッションのルートからの相対）の `YYYY-MM-DD-prompt-analysis.md` に書く。

## 分析の観点

| 観点 | 判定 |
|---|---|
| 要件の小出し | 1セッションで20件以上のプロンプト |
| 指示語だけ | 30文字以下で「それ」「お願いします」などで始まり、パス・URL・番号を含まない |
| 肥大 | 20,000文字以上 |
| 誤送信の疑い | 3文字以下（スラッシュコマンドと「はい」などの定型を除く） |

判定は文字列による機械的なもので、LLM は使わない。結果は候補であり、判断は利用者が行う。

## 制約

- 対象はユーザー行（tool_result・サブエージェント・システム注入を除く）。
- 取得に `find` と `grep` を使う。
- レポートにはプロンプトの先頭40文字を例として載せる。共有するリポジトリへ置くときは内容を確認する。
